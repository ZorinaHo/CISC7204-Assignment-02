# Lab 01 · Automobile Sales Visualizations

This portfolio version of my final-project Lab 01 shows selected recession comparisons from my submitted notebook. It includes [the analysis script](../analysis.py), [annual sales chart](../visualizations/annual-sales.png) and [vehicle-type chart](../visualizations/sales-by-vehicle-type.png).

The [public notebook](visualizations.ipynb) includes three chart cells from my submission. Install `jupyter`, `pandas`, `matplotlib` and `seaborn` in your Python environment, then open the notebook and run all cells. It loads the provider CSV directly.

From the repository root, run `python -m pip install -r requirements.txt` and `python analysis.py`. The script reads the provider CSV and recreates both figures.
