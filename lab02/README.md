# Lab 02 · Interactive Automobile Sales Dashboard

The [Dash app](dashboard.py) switches between recession-period statistics and a report for a selected year. Each view displays four Plotly charts. The year selector is available in the yearly report.

1. Download the [IBM Skills Network course CSV](https://cf-courses-data.s3.us.cloud-object-storage.appdomain.cloud/IBMDeveloperSkillsNetwork-DV0101EN-SkillsNetwork/Data%20Files/historical_automobile_sales.csv).
2. Save it as `automobile-sales.csv` beside `dashboard.py`.
3. From this folder, run `python -m pip install -r requirements.txt` and `python dashboard.py`.
4. Open [the local dashboard](http://127.0.0.1:8050/).

The course data describe an educational exercise. The yearly and recession charts summarize the supplied records.
